# 🎴 Memory Game

Интерактивная браузерная игра на запоминание карточек (Memory Pair Matching Game), написанная на чистом JavaScript (Vanilla JS), HTML5 и CSS3.

![Memory Game Preview](![alt text](image.png))

---

## 🚀 Особенности приложения

- 🎲 **Динамическая генерация поля**: Сетка карточек $4 \times 4$ генерируется и случайным образом перетасовывается при каждом старте.
- ⏱️ **Статистика в реальном времени**:
  - Подсчёт количества сделанных ходов.
  - Счетчик найденных пар ($0 / 8$).
  - Секундомер, отслеживающий время прохождения игры (запускается с первым кликом).
- 💾 **Сохранение прогресса**: Состояние игры и текущие карточки сохраняются в `localStorage`, что позволяет продолжить игру после перезагрузки страницы.
- 🔄 **Управление игрой**:
  - Кнопка **«Новая игра»** для быстрого перезапуска с новым расположением элементов.
  - Кнопка **«Сбросить прогресс»** для очистки сохранённого состояния и полного сброса.
- 🎨 **Адаптивный интерфейс**: Вёрстка выполнена на базе CSS Grid и Flexbox.
- ⚙️ **Чистый код**: Элементы интерфейса создаются динамически через манипуляции с DOM без использования библиотеки `innerHTML`.

---

## 🛠️ Технологический стек

- **HTML5**: Семантическая разметка (`<header>`, `<main>`).
- **CSS3**: BEM-методология, CSS Grid, 3D-трансформации (`perspective`, `rotateY`) для анимации переворота карточек.
- **JavaScript (ES6+)**:
  - DOM API.
  - `localStorage` API для сохранения прогресса.
  - Тасование элементов по алгоритму `Math.random()`.
